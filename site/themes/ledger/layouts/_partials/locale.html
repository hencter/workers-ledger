{{- /* 返回站点的语言标识（如 zh-CN），跨 Hugo 版本可用。 为什么不能碰 site.Language 对象：在 Hugo < 0.158 上访问 `.Locale` 会**直接抛错** （can't evaluate field Locale in type *langs.Language）， 连 `with site.Language.Locale` 都拦不住——模板求值失败发生在 with 判断之前。 本项目第一版兼容写法就栽在这里，把只坏一个渲染点的故障扩大成了 partial 内部报错。 所以改成**完全绕开语言对象的字段**，改读配置：hugo.toml 的 params.locale 是普通字符串参数，任何 Hugo 版本都读得到，语义也更明确。 兜底顺序：params.locale（本项目配置）→ 参数 locale → 常量 zh-CN。 */ -}} {{- $loc := "zh-CN" -}} {{- with site.Params.locale -}} {{- $loc = . -}} {{- end -}} {{- return $loc -}}
