{{- /* 发布配置读取器 —— 从 Hugo data 里取 site.config.json 的内容。 数据由 tools/build-site.mjs 在生成阶段写入 site/data/site.json， 来源是仓库根唯一的 site.config.json（改域名、改仓库只改那一个文件）。 ## 为什么绕这一道 - 不写进 hugo.toml：那会出现**第二个真相源**，改一个忘一个的那天， 页脚链接会指向已废弃的仓库，而页面看起来完全正常； - 不用 resources.Get "site.config.json"：Hugo 在 site/ 下**读不到**仓库根的文件 （实测该方式取不到值，链接不渲染）。 由生成脚本转成 data 最稳，且来源仍只有一份。 取不到时返回空串，调用方用 {{ with }} 决定是否渲染—— **不要在这里退回硬编码地址**：硬编码正是要避免的东西。 */ -}} {{- $cfg := hugo.Data.site | default dict -}} {{- return (dict "repo" ($cfg.repo | default "") "repoURL" ($cfg.repoURL | default (cond (ne ($cfg.repo | default "") "") (printf "https://github.com/%s" $cfg.repo) "")) "publishUrl" ($cfg.publishUrl | default "") "domain" ($cfg.domain | default "") "hosting" ($cfg.hosting | default "") ) -}}
