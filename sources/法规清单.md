本文件是全书条目的**依据注册表**。条目的「依据」「来源」两栏只能引用本表编号，不得另找链接。

字段口径按 `docs/条目规范.md`：效力位阶取 法律 / 行政法规 / 部门规章 / 地方性法规 / 司法解释 / 规范性文件 / 地方口径。

**信源优先级**（按 `docs/条目规范.md` 与任务约定）：
1. 国家法律法规数据库（flk.npc.gov.cn）、中国政府网（gov.cn）、中国人大网（npc.gov.cn）、最高人民法院（court.gov.cn）、国家行政法规库（xzfg.moj.gov.cn）

## 五、待办与不确定（本仓库最看重的部分，请勿删除）

核验员如实记录未拿到一手源或存在版本疑点的项，不臆造、不填补。

1. **国家法律法规数据库（flk.npc.gov.cn）未能用于自动化取原文。** 该站为单页应用，详情页链接无稳定永久地址（形如 `/detail2.html?<版本标识>`，标识为会话态加密串）。核验员实测：
   - `GET https://flk.npc.gov.cn/` → HTTP 200，页面标题「国家法律法规数据库」，源码仅 552 字节，正文由脚本渲染，取不到条文；
   - `POST https://flk.npc.gov.cn/law-search/search/list` → HTTP 200 但响应体为 `{"msg":"系统异常","code":500}`，尝试 10 种请求体字段组合（`title`/`keyword`/`fgmc`/`searchValue`/`searchParams` 等）与 6 种分页字段，全部返回同一错误；
   - `GET https://flk.npc.gov.cn/law-search/search/flfgDetails?bbbs=<标识>` → 可返回法规元数据（发布机关、公布日期、历次版本、相关文件），但前提是已知道版本标识，而获得标识的检索通道不可用。
   **结论**：本表未使用 flk.npc.gov.cn 作为条目的唯一来源；相关法规改用中国人大网、中国政府网、国家行政法规库、最高人民法院等同为官方一级来源的静态全文页。保留此记录，供后续换源与人工复核。

2. **《劳动合同法》现行合订本缺国务院系统一手页。**
   - 中国人大网的《劳动合同法》页（L01 第一条 URL）实测为 **2007 年通过之原文**，页面标题下仅注「（2007年6月29日第十届全国人民代表大会常务委员会第二十八次会议通过）」，全文不含「2012」「修正」字样，**不能当作 2012 修正后的现行本直接引用**。
   - 2012 年修正的事实本身已由一手源确认：全国人大常委会《关于修改〈中华人民共和国劳动合同法〉的决定》全文（<http://www.npc.gov.cn/npc/c2/c12435/c12488/201905/t20190522_76069.html>，HTTP 200），该决定**只修改第五十七条、第六十三条、第六十六条、第九十二条**，自 2013-07-01 施行。
   - **由此可推**：本书记录的其余条文（第四、十、十九、二十、三十五、三十六、三十七、三十八、三十九、四十、四十一、四十二、四十四、四十六、四十七、四十八、五十、八十二、八十五、八十七、九十条）在 2012 年修正中未被改动，2007 年原文与现行本文字一致。核验员已用北京市人民政府门户网站转载的 2012 修正后重新公布本逐条比对，二十一条全部一致。
   - **待办**：如后续取得国家法律法规数据库可用的现行合订本永久链接，把 L01 的来源栏换成一手页并删除本条。

3. **《劳动法》的现行版本链接目前是地方政府转载页。** L03 指向广东省人民政府门户网站，该页自身标注「来源：中国人大网」并载明两次修正沿革（2009-08-27 第一次、2018-12-29 第二次）。核验员未在中国人大网、中国政府网找到可比对的静态全文页。**在换到一手源之前，凡引用《劳动法》条文的条目，来源栏必须保留「转载页，待换一手源」标注。**

4. **《工伤保险条例》在国家行政法规库内有两条并存，其中一条是 2010 年修订前旧版。** `LawID=610` 为现行本，`LawID=950` 为旧版（第十四条第六项仍写「机动车事故伤害」，一次性工亡补助金仍写「48 个月至 60 个月统筹地区上年度职工月平均工资」）。两者均出现在该库「现行有效」检索结果中，页面无「已废止」标记。**引用一律用 610。** 核验员已据此纠正条文摘录，详见 `sources/条文摘录.md` G03 节的警示表。

5. **任务清单中的两处条号需更正。**
   - 「工伤保险条例第三十三条」：现行本第三十三条即停工留薪期规定，**任务清单的条号是正确的**。核验员第一轮曾误按旧版改记为第三十一条，已纠正。
   - 「工伤保险条例第三十七条」：现行本中工亡待遇条款为**第三十九条**（2010 年修订由原第三十七条改为第三十九条，待遇标准亦有实质变动）。第五十七、六十六、九十二等条号不受影响。
