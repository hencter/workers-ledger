## 七、发现错误怎么提

**每条内容的页面底部都有一个「在 GitHub 上提 issue」按钮**，点一下直达新建 issue 页，
标题与正文**已经替你填好**——条目编号、书上写的「依据」「来源」「核对日期」都在里面，
你只需补两样：

1. **你核对的官方页面地址**（浏览器地址栏复制粘贴）；
2. **页面上实际写的内容**（直接复制粘贴原文，不要转述）。

有这两样我们才能核对。只有一句「这条好像不对」，我们既无法采信也无法定位——不是不欢迎，
是没办法用。

> [!tip] 提之前值得知道的三件事
> - **只要官方一手材料**：官网页面、官方 PDF、政府公报。公众号、新闻、法律咨询网站、AI 回答
>   都只能算二手转述，我们会标注「未采信」。
> - **「我查不到原文」也是有价值的信息**。请写清你查了哪些地方、用了什么关键词——这能告诉我们
>   某条规定是不是真的不存在（本书「仲裁排期没有法定期限」那一条就是这么来的）。
> - **不要写个人信息**：不需要姓名、单位、联系方式。涉及你自己的案子时，只描述条文本身的问题就够。
