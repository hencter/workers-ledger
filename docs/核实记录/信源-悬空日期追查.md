# 信源核验记录：住房公积金管理条例「2026-08-10」追查（已结案：是真实修订）

记录人：信源核验员
起始日期：2026-10-03（第二轮登记时发现异常）
结案日期：2026-10-03（第三轮追查）
结论：**不是悬空日期，是真实的第三次修订；核验员前一轮的判断有误，已更正**

---

## 一、案件的来龙去脉

### 第二轮：发现异常，但判断错了

核验员应 lead 要求补登《住房公积金管理条例》时，取的是国家行政法规库 `LawID=521` 页。该页有两个互相矛盾的地方：

1. **页内版本说明**只列到 2019-03-24：「(1999年4月3日中华人民共和国国务院令第262号发布　根据2002年3月24日《国务院关于修改〈住房公积金管理条例〉的决定》第一次修订　根据2019年3月24日《国务院关于修改部分行政法规的决定》第二次修订)」——只读到这里，会以为现行本就是 2019 年第二次修订本。
2. **页内「历史沿革」区块**却列了四项日期：1999-04-03、2002-03-24、2019-03-24、**2026-08-10**。

核验员当时的处理是：**把 2026-08-10 判断为「查不到对应修订文件的悬空日期」**，在 `sources/法规清单.md` 里写成「版本沿革存疑」，并把它列进待复核清单，注明「不能断定现行本已含 2026 年的改动」。

**这个判断是错的。** 错在只读了 `LawID=521` 一个页面，没有点开历史沿革里那条 2026-08-10 记录所链接的目标页。

### 第三轮：点开链接，问题当场解决

按 lead 要求「把尝试路径写细」，核验员重新抓取 `LawID=521` 页的原始 HTML，把「历史沿革」区块的链接逐个解出来：

| 历史沿革日期 | 指向的 LawID |
| --- | --- |
| 1999-04-03 | `LawID=1221` |
| 2002-03-24 | `LawID=1222` |
| 2019-03-24 | `LawID=521` |
| **2026-08-10** | **`LawID=1822`** |

**2026-08-10 那一条是带链接的，指向 `LawID=1822`。** 打开该页，页内版本说明为：

> (1999年4月3日中华人民共和国国务院令第262号发布　根据2002年3月24日《国务院关于修改〈住房公积金管理条例〉的决定》第一次修订　根据2019年3月24日《国务院关于修改部分行政法规的决定》第二次修订　**根据2026年8月10日《国务院关于修改〈住房公积金管理条例〉的决定》第三次修订**)

**案件到此结案：2026-08-10 是真实的第三次修订，《住房公积金管理条例》现行本为 `LawID=1822`。**

## 二、根因：同一个库内，旧版页面不自我标注「已被取代」

这是本次事件最值得记住的一点，也是与《工伤保险条例》案例同源的结构性问题：

- `LawID=521`（2019 年第二次修订本）**页内没有「已废止」「已被修改」字样**，其版本说明也只写到自己那一次修订为止。
- 它当然也不会说「有更新的版本」——**旧版页面不会主动告诉你它不是最新的**。
- 唯一暴露线索的，是它自己的「历史沿革」区块里那条**指向新版的链接**。而那条线索需要**点进去**才能兑现。

**核验员的失误在于：看到了线索，却没有顺着线索走到底，反而把线索本身当成了「数据错误」。** 这是「遇到异常先怀疑数据、而不是先追踪数据」的典型。

**强制动作（已加入本仓库核对纪律）**：官方页若出现「历史沿革」「历次版本」这类区块，**必须把区块内每一个日期对应的链接都点开**，直到确认最新一版；不能只看页内版本说明就下结论，也不能把区块里读不懂的日期当作噪声。

## 三、从旧版到现行本的实际变化（本书直接相关）

| 内容 | 2019 年第二次修订本（`521`，已取代） | **2026 年第三次修订本（`1822`，现行）** |
| --- | --- | --- |
| 条文总数 | 47 条 | **50 条** |
| 不办缴存登记、不设账户的罚则 | **第三十七条**：「……责令限期办理；逾期不办理的，处 **1 万元以上 5 万元以下**的罚款。」 | **第三十九条**：「……责令限期办理；逾期不办理的，处 **5 万元以上 30 万元以下**的罚款。」 |
| 逾期不缴、少缴的强制 | **第三十八条**：「……责令限期缴存；逾期仍不缴存的，可以申请人民法院强制执行。」 | **第四十条**（内容不变，仅条号后移） |
| 缴存比例 | 第十八条：「均不得低于……**5%；有条件的城市，可以适当提高缴存比例**。」 | 第十八条：「均不得低于……**5%，不得高于国家规定的最高缴存比例**。」 |
| 单位困难可降低比例或缓缴 | 原第二十条第二款 | 已不在第二十条内（2026 本第二十条只有一款） |
| 缴存登记办理 | 第十五条 | 第十五条（内容不变，条号未动） |

**新增条文**：第四十八条、第四十九条、第五十条。其中第四十九条为灵活就业人员自愿缴存的新规定：

> 第四十九条　个体工商户、非全日制从业人员以及其他灵活就业人员，可以自愿缴存住房公积金，按照规定享受相应的政策支持。具体办法由国务院住房城乡建设主管部门制定。

## 四、对本书的影响（须转正文作者）

1. **`book/07-社保公积金与失业之后.md` 第 7 节**引用本条例的条目，条号须调整：
   - 「第三十七条」（不办登记罚则）→ **第三十九条**
   - 「第三十八条」（逾期不缴强制）→ **第四十条**
2. **罚则金额须同步更正**：书稿若写「处 1 万元以上 5 万元以下罚款」，按现行本应为「**5 万元以上 30 万元以下**」。这是 5 倍的差距。
3. **第十八条的表述须更正**：现行本增加了上限限制（不得高于国家规定的最高缴存比例），不只是「不得低于 5%」。
4. **第二十条的缓缴条款已不在该条内**，若书稿引用了缓缴内容，须重新定位。
