**同站点的 IP 通道可用**：`http://114.255.111.133/` 与 `http://114.255.111.180/` 返回同一站点内容（页面内 `<meta name="SiteDomain" content="www.mohrss.gov.cn" />`、`网站标识码 bm15000008`、页脚「主办单位：中华人民共和国人力资源和社会保障部」）。

**这条通道的可信度证据（两条，互相独立）**：

1. 2025 年度公报附件 PDF 经 IP 通道抓取，SHA256 前 16 位 `fad80d0fdf2d4121…`，字节 472345；经 `www.mohrss.gov.cn` 直连抓取，字节同为 472345、SHA256 前 16 位同为 `fad80d0fdf2d4121…` —— **两条通道拿到的是同一份字节**。
2. 经 IP 通道抓到的页面里，`<meta name="Url">` 字段本身就写着 `www.mohrss.gov.cn` 的地址。例：2017-05-25 那页的元数据为 `ArticleTitle=完善制度 规范程序 提升效能`、`PubDate=2017-05-25 11:17:00`、`ContentSource=人社部`、`Url=http://www.mohrss.gov.cn/SYrlzyhshbzb/zcfg/SYzhengcejiedu/201705/t20170525_271407.html`。故：内容可作一手证据，但**正式登记来源时应写 `www.mohrss.gov.cn` 的规范 URL**，并注明本机直连该 URL 会落到反爬页。

以下各行如无特别说明，「实测 URL」列为 IP 通道地址，「规范 URL」为该页在 `www.mohrss.gov.cn` 下的对应地址。

## 七、给仓库的几条明确提醒（与既有结论有出入的地方）

1. **AGENTS.md 里「省级公报可以拿到仲裁案件量（例如浙江、山东）」对浙江不成立。** 实测浙江 2025 与 2023 两份省级公报都**只有**调解成功率与仲裁结案率（2023 年另有「63 家仲裁机构」），**没有收案量**。山东成立，但山东用的是「**受理**」口径（21.9 万／21.5 万件）。江苏、北京的公报也有收案量，可以补进例子。
2. **全国「立案量」有两套官方口径，差三倍，绝不能混用**：
   - 公报口径：「全年全国各级劳动人事争议**调解组织和仲裁机构共办理**劳动人事争议案件」——2024 年 **425.7 万件**（含各类调解组织）。
   - 快报／年鉴口径：「**仲裁委员会立案受理**的争议案件数」——2024 年 **168.6 万件**（仅仲裁机构）。
   - 写条目时若说「全国每年仲裁立案约 X 万件」，只能用后者（168.6 万），并写明是「仲裁委员会立案受理」。
3. **「按 AGENTS.md 说 PDF 抽取未能还原」这条要更新**：本次零依赖抽取器对**人社部公报与快报那类 PDF**（Type0 + Identity-H + ToUnicode，无 ObjStm）是**可用**的，2019–2025 七份公报、六份快报都抽出了完整正文；对**含 ObjStm／无 ToUnicode 的 PDF**（如仲裁院单位决算）仍然完全抽不出。也就是说：不是「PDF 一律抽不出」，而是「分两类，一类能一类不能」。

## 八、方法与局限

### 8.1 本次用到的取证方式

- **HTTP 实测**：Node 24 `fetch`，UA 为桌面 Chrome；每页记录状态码、最终 URL、Content-Type、字节数、SHA256。
- **HTML → 纯文本**：自写块级标签换行 + 实体解码（与 `tools/抽原文.mjs` 同思路，但**复制实现、不 import**，因为该脚本是「可执行脚本 + 库」混写，import 会触发它的主流程并往 `sources/.原文缓存/` 写文件——本次被要求不碰 `sources/`）。
- **PDF → 文本**：自写零依赖抽取器（解析间接对象 → FlateDecode → 解析 ToUnicode CMap → 按 Tm/Td 的 y 坐标断行 → 解 Tj/TJ 的十六进制串）。约 130 行，全在 `.tmp-research/pdf文本.mjs`。
- **年鉴表格 → 数值**：表是 JPG，改用读图（`read_image`）逐格辨认。
- **docx → 文本**：按 Node 内置 zlib 手工解 `word/document.xml`。
- **GB2312 页面**：国家统计局年鉴页是 GB2312，用 `TextDecoder('gb18030')` 解码后定位框架页与目录帧。

### 8.2 必须写明的局限

1. **PDF 抽取是版面近似重建，不是逐字保真文本。** 抽取器按 y 坐标断行、按 x 间距补空格；公报 PDF 的一页表头有时会被拼进句子里（例如 2024 年公报抽出文本里出现过 `=====第10页=====10办结争议案件415.6万件`）。**数字本身可靠**（已交叉验证），但**排版不能当原文版式引用**。正式引用前建议再打开 PDF 目视一次。
2. **年鉴数字是读图得到的。** 733×894 / 738×887 px 的 JPEG，逐格辨认。已与快报 PDF 交叉验证一致，但仍属**人工目视读图**，不是文本层取数。
3. **IP 通道（114.255.111.133 / 114.255.111.180）不是规范来源。** 页面自带 `SiteDomain=www.mohrss.gov.cn`，且同一份 PDF 的 SHA256 与 `www` 直连完全一致，故内容判定为同源；但**书里的来源栏应写 `www.mohrss.gov.cn` 的规范 URL**，并可在核实记录里注明本机直连会落到反爬页。
4. **2019 年快报的附件是 .xls**（`W020200121546291104371.xls`），本机无零依赖 xls 解析路径，**该项未抽取**。
5. **本次只逐份抽取了 2019–2025 七份年度公报与 2020–2025 六份年度快报**（1992–2018 的公报、2019 年快报未抽）。因此「仲裁员人数、仲裁机构数从未出现在全国公报里」这一判断，**范围仅限本次抽取的那几份**，不能扩大成「历来没有」。
6. 人社部站内检索不可用（6.6），使「某说法在人社部网站上是否存在」这类否定性判断**在本次调查中不可得**。
7. 本次**未**核实：地方仲裁委的排期时长、每名仲裁员的办案量（除重庆区县口径外）、各省仲裁员人数的完整分布。
