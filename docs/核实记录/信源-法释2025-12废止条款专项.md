# 信源核验记录：法释〔2025〕12 号版本时效专项

记录人：信源核验员
核验日期：2026-10-03（东八区）
核验对象：《最高人民法院关于审理劳动争议案件适用法律问题的解释（二）》（法释〔2025〕12 号）及其对解释（一）（法释〔2020〕26 号）的废止效力

---

## 一、结论先行

1. 法释〔2025〕12 号于 **2025-02-17** 经最高人民法院审判委员会第 1942 次会议通过，**2025-07-31** 公布，**2025-09-01** 施行。
2. 该解释第二十一条明确废止的是——**《最高人民法院关于审理劳动争议案件适用法律问题的解释（一）》（法释〔2020〕26 号）第三十二条第一款**。
3. **只废止第三十二条第一款，不废止第三十二条整条，也不废止解释（一）的其他任何条款。** 第三十二条第二款仍然有效。
4. 该解释同时规定「最高人民法院此前发布的司法解释与本解释不一致的，以本解释为准」——这是一条兜底条款，意味着**解释（一）中被本解释实质改变的其他条文，即使未被逐条点名废止，也不得再按原口径引用**。

## 二、被废止条文原文（逐字）

来源：S01，《最高人民法院关于审理劳动争议案件适用法律问题的解释（一）》第三十二条，取自最高人民法院官网 <https://www.court.gov.cn/zixun/xiangqing/282121.html>（HTTP 200，2026-10-03 实测）。

**第三十二条第一款（已废止）：**

> 用人单位与其招用的已经依法享受养老保险待遇或者领取退休金的人员发生用工争议而提起诉讼的，人民法院应当按劳务关系处理。

**第三十二条第二款（仍然有效）：**

> 企业停薪留职人员、未达到法定退休年龄的内退人员、下岗待岗人员以及企业经营性停产放长假人员，因与新的用人单位发生用工争议而提起诉讼的，人民法院应当按劳动关系处理。

## 三、废止条款原文（逐字）

来源：S02，《最高人民法院关于审理劳动争议案件适用法律问题的解释（二）》第二十一条，取自最高人民法院公报 <http://gongbao.court.gov.cn/Details/bb72019c45453f84d920bd6375573e.html>（HTTP 200，2026-10-03 实测）。

> 第二十一条　本解释自2025年9月1日起施行。《最高人民法院关于审理劳动争议案件适用法律问题的解释（一）》（法释〔2020〕26号）第三十二条第一款同时废止。最高人民法院此前发布的司法解释与本解释不一致的，以本解释为准。

## 四、实务影响（写给条目作者）

1. **2025-09-01 之前**：已享受养老保险待遇或领取退休金的人员再就业，与用人单位发生用工争议，按**劳务关系**处理——不受劳动法调整，无经济补偿、无二倍工资、不走劳动仲裁。
2. **2025-09-01 起**：这一规则**不再有效**。该类争议的定性回到一般规则，需按实际情况判断，**不再当然按劳务关系处理**。
3. 需要注意的是，解释（二）全文（第一条至第二十一条）中**未出现「退休」二字**，也未就退休人员再就业给出新的替代规则。也就是说，被废止后留下的是**空白**，而非被新规则覆盖。这是本条最需要标注不确定的地方。
4. **条目写作红线**：
   - 凡涉及「退休人员再就业定性」的条目，**禁止引用解释（一）第三十二条第一款**。
   - 凡涉及「停薪留职、内退、下岗待岗、经营性停产放长假人员与新单位按劳动关系处理」的条目，**仍可引用第三十二条第二款**。
   - 主张强度建议按 `可推定` 处理，并在「备注」写明：该问题自 2025-09-01 起因解释（一）第三十二条第一款被废止而处于规则空白期，各地口径可能不一致，具体请咨询用工所在地劳动人事争议仲裁委员会。
