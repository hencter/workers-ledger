# 仲裁的「沉默成本」：排期没有法定期限

**日期**：2026-10-03
**起点**：一个问题——书里写的是**法定时效**（仲裁一年、审理 45＋15 日），但没写**从立案到开庭要等多久**。而地方仲裁委人少、案子多，等待是当事人真正要承担的沉默成本：**赢了裁决却等了半年，收益被时间吃掉。**

## 一、结论：法定时效 ≠ 拿到钱的时长

《劳动争议调解仲裁法》第四十三条与《劳动人事争议仲裁办案规则》第四十五条给的是「**受理之后** 45 日，可延 15 日」。**从递交材料到受理**、**从受理到开庭**、**从裁决到拿到钱**，这三段不在这个期限内。

新增条目 [book/14 第 14.29 条](../../book/14-仲裁与诉讼实操.md) 把各环节法定期限列全，并明确「排期没有法定期限」。

## 二、各环节法定期限（逐条摘录，均已入 `sources/条文摘录.md` B10 块）

依据：**《劳动人事争议仲裁办案规则》**（人力资源和社会保障部令第 **33 号**，2017-05-08 公布，**2017-07-01 施行**；同时废止 2009 年人社部令第 2 号）。已登记为 `sources/法规清单.md` **B10**。

| 环节 | 条文 | 期限 |
| --- | --- | --- |
| 材料补正一次性告知 | 第二十九条 | 当场或 **5 日**内 |
| 出具受理通知书 | 第三十条 | 收到申请起 **5 日**内 |
| 不予受理通知 | 第三十一条 | **5 日**内 |
| **逾期未决定的救济** | 第三十一条 | 逾期未作决定或决定不予受理 → **可直接向人民法院起诉** |
| 送达申请书副本 | 第三十三条 | 受理后 **5 日**内 |
| 答辩 | 第三十三条 | 收到副本后 **10 日**内 |
| 组成仲裁庭 | 第三十七条 | 受理起 **5 日**内 |
| **开庭通知** | 第三十八条 | **开庭 5 日前**书面通知 |
| 请求延期开庭 | 第三十八条 | **开庭 3 日前** |
| 裁决 | 第四十五条 | 受理起 **45 日**，经书面批准可延 **15 日** |
| **期限重新计算** | 第四十六条 | 追加当事人或第三人、补正材料、增加或变更请求、反申请合并、移送管辖 → **重新计算**；中止审理、公告送达 → **不计入** |
| 集体争议特别规定 | **第六十四条** | 受理起 **5 日**内一次性通知开庭日期等事项 |

## 三、核心发现：排期没有法定期限（普通个案）

**法律要求仲裁庭在开庭 5 日前通知你，但没要求「受理后多少日内必须开庭」。** 这是「等待」无法定上限的直接原因。

**机械证据（可重跑）**：通检《办案规则》全文 81 条——

| 检索项 | 结果 |
| --- | --- |
| 「日内开庭」 | **0 处** |
| 「开庭期限」／「开庭的期限」 | **0 处** |
| 「排期」 | **0 处** |
| 「多少日内开庭」 | **0 处** |
| 「重新计算」 | **6 处**（第四十六条） |
| 「不计入」 | **1 处**（第四十六条第六项） |

**唯一涉及「受理之日起……开庭日期」的是第六十四条**，属**第四节 集体劳动人事争议处理**，适用对象是**集体争议**；普通个案适用第三十八条。

> **口径限定（必须与条目表述一致）**：这是「**没有找到规定**」，不等于「证明不存在规定」。检索范围限于本规则全文；《劳动争议调解仲裁法》第四十三条只规定审理期限，也未规定排期。凡引用本条结论，不得省略这句限定。

## 四、数据可得性：能拿什么、拿不到什么

用户问的是「每个地方的仲裁委员会人数、对应工作人口、历年占比」。**这个数据集的现状必须如实说清**：

| 想要的 | 可得性 | 说明 |
| --- | --- | --- |
| 仲裁**案件量**（省级） | **可得** | 省级《人力资源和社会保障事业发展统计公报》公布，例如浙江、山东（浙江为 PDF） |
| 全国**收案量** | 待核 | 人社部《人力资源和社会保障事业发展统计公报》口径，见 `docs/核实记录/信源-仲裁案件量与人员编制调查.md` |
| **每个仲裁委的仲裁员人数** | **无全国统一口径** | 编制数通常在地方编制文件或年报里，不构成可比的公开序列 |
| **人均办案量** | **无全国统一口径** | 未找到官方发布的人均办案统计 |
| **当地排期时长** | **无公开数据** | 这正是第 14.29 条教读者「去问」而不是「去查」的原因 |
| 「案多人少」的官方承认 | 待核 | 见上述调查记录 |

**已知一项官方旁证**（已登记为 `sources/法规清单.md` **P01**）：北京市司法局公布的 12348 热线 2025 年度运行情况——民事类工单中**劳动劳务纠纷咨询占 23.28%，占比最多**，第二位是「诉讼或劳动仲裁程序咨询」。这说明「怎么走程序、要等多久」本身就是高频需求，而不是少数人的困惑。

## 五、试过但未成功：省级公报 PDF 的机械抽取

浙江 2023 年度人社统计公报为 **PDF**（`zjjcmspublic...pdf`，HTTP 200，196,803 字节，有 21 个 FlateDecode 流）。本项目为它写了一个**零依赖 PDF 文本抽取器**（Node 内置 `zlib` 解流 + 解析 ToUnicode CMap）：解出 21 个流、7 份 CMap、556 个码位映射，抽出 7,277 字符，**但中文无法正确还原**（CMap 基址偏移，例如「浙江省」被还原成「浙江终」）。

**处理**：不再在 PDF 解析上投入，**如实记为「尝试过但未能机械提取原文」**。要用省级 PDF 数据，应优先找同一公报的 HTML 版页面，或人工打开 PDF 核对。抽取脚本留在 `.tmp-research/`（gitignore，不随仓库发布）。
