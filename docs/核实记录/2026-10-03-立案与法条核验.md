# 仓库建立时的条文核验记录

日期：2026-10-03
范围：第 1 节「签合同之前」、第 2 节「在职工资与工时」全部条目的法条依据

## 核验方法

条文一律取自官方静态全文页，用命令行工具取回原始内容后逐字抽取比对，不采信任何二次转述。取回的原始内容当时留在 `.tmp-verify/`（已列入忽略，不进版本库）。

取核过程中确认了两个技术事实，记录下来供后续核验参考：

1. **国家法律法规数据库（flk.npc.gov.cn）是单页应用**，直接请求返回的是约 534 字节的页面外壳，取不到条文正文，且详情页标识是会话态加密串、无稳定永久链接。因此它只能作为检索入口使用，**不能作为条目的「来源」栏链接**。正式来源改用中国人大网与中国政府网的静态全文页。
2. **本机网络环境对 gov.cn 系域名的解析被指向保留地址段**（实测解析结果落在 198.18.0.0/15），浏览器以外的常规抓取工具会被安全策略直接拒绝。改用命令行 HTTP 客户端请求可正常返回。后续核验统一走命令行取原文。

## 第二轮核验（同日补充）

### 《中华人民共和国劳动法》官方来源：先误用，后更正

**更正说明（重要）**：本节最初记录的来源是商务部政策法规库页面 `policy.mofcom.gov.cn/claw/clawContent.shtml?id=66953`，并把它评价为「一手来源级别的页面」。**该结论已被推翻，此来源已弃用**，理由如下（由信源核验任务独立核查，记录见 `docs/核实记录/信源-部委法规库页面性质核查.md`）：

1. 该站页面底部自带免责声明：「本网站提供的法规来源于数据提供单位或网络，网站**不对法规内容的准确性负责**，请务必与正式文本核对后使用。」一个自称不保证准确性的页面，接不住本仓库「来源必须能逐字核对」的要求。
2. 同一库内各页来源分档不一：本书用到的《劳动法》《社会保险法》两页标注「信息来源：全国人大网」，但《劳动合同法》对应页标注的是商业数据库，且正文夹带「第一条【立法宗旨】……」这类官方文本没有的编辑标注，证明其不逐字保真。
3. 该站声明禁止自动化采集，而 `tools/check-sources.mjs` 会自动抓取注册表中每条链接。登记它等于让日常校验长期违反站点声明。

第 2 节 2.1 的「来源」栏已改为中国人大网的一手页：

`http://www.npc.gov.cn/npc/c2/c30834/201905/t20190521_296651.html`

实测 HTTP 200，页面标题「中华人民共和国劳动法_中国人大网」，页内载明沿革：1994-07-05 通过；根据 2009-08-27《关于修改部分法律的决定》第一次修正；根据 2018-12-29《关于修改〈中华人民共和国劳动法〉等七部法律的决定》第二次修正。共 107 条。

**逐字比对通过**：第四十四条三项加班费标准为「安排劳动者延长工作时间的，支付不低于工资的百分之一百五十的工资报酬」「休息日安排劳动者工作又不能安排补休的，支付不低于工资的百分之二百的工资报酬」「法定休假日安排劳动者工作的，支付不低于工资的百分之三百的工资报酬」。

**这次误用的教训值得写下来**：一个页面「能打开、元数据齐全、看起来像官方」，不等于它是可用的一手来源。判据不是页面观感，而是**这个来源自己怎么声明它的可靠性，以及它是否允许我们这样使用它**。来源审查要看页面底部，不只看页面标题。

### 《企业职工带薪年休假实施办法》第五条、第四条补齐

同一政府网页在第二轮取数中把被截断的条文取全，并额外核到两条对正文有实质影响的表述：

- **第五条**：「职工新进用人单位且符合本办法第三条规定的，当年度年休假天数，按照在本单位剩余日历天数折算确定，折算后不足1整天的部分不享受年休假。前款规定的折算方法为：（当年度在本单位剩余日历天数÷365天）×职工本人全年应当享受的年休假天数。」——据此新增第 2 节 2.5 条
- **第四条**：「年休假天数根据职工累计工作时间确定。职工在同一或者不同用人单位工作期间，以及依照法律、行政法规或者国务院规定视同工作期间，应当计为累计工作时间。」——这是「累计工作」不等于「本单位工作」的直接条文支撑，比原先仅凭条例推断更硬
