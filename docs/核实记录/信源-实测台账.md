记录人：信源核验员
核验日期：2026-10-03（东八区）
核验工具：命令行 HTTP 客户端（PowerShell `Invoke-WebRequest`）
核验方式：逐个 URL 实际发起请求，记录**状态码**、**页面标题**、**是否取到正文**。

> [!note] 为什么不用浏览器的网页抓取工具
> 本机域名解析把 `gov.cn` 系域名指向保留网段，网页抓取工具对这类站点一律报「解析到非公网地址」而失败。这是**本机解析环境的问题，不代表链接失效**。因此本次核验全程改用命令行 HTTP 客户端直连，结果等效于浏览器打开。凡下列台账中标「已取到正文」的，均为当场读到条文原文。

## 四、核验结论

1. 全书条目所需的主要法规，**均已取得官方一级来源的全文**，可直接支撑「依据」「来源」两栏。
2. 存在两处版本风险已定性并留档：**《劳动合同法》的现行合订本来源**与**《工伤保险条例》的库内新旧版并存**。
3. ~~存在一处来源降级：《劳动法》目前只有地方政府转载页。~~ **已解决**：第二轮已定位到中国人大网一手页（序号 28），来源升级完成。
4. 存在两处新增待复核：**《住房公积金管理条例》历史沿革中的 2026-08-10**、**《反不正当竞争法》在注册表中未登记**。
5. 全仓条号审计已完成，结论见 `docs/核实记录/信源-全仓条号审计.md`：**360 处引用中发现 1 处硬错**（反不正当竞争法第十条第四款不存在），其余 188 组条号全部与官方原文一致。
6. 本次核验**未凭记忆填写任何条号、文号或链接**。所有写入 `sources/` 的文字，均由上述实测页面逐字抄录。

## 五、本台账的维护约定

1. 每新增或更换一个来源 URL，必须在本台账追加一行（状态码、页面标题、是否取到正文、日期）。
2. 每发现一处「官方库内新旧版并存」「站点自带免责声明」这类陷阱，必须同时写入 `sources/法规清单.md` 的警示区与独立核实记录，不能只留在会话里。
3. 本台账只记录**实测结果**，不记录推测。推测的地址即使 404 也要写明「推测」二字。
