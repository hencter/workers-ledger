记录人：信源核验员
核验日期：2026-10-03（东八区）
核验工具：命令行 HTTP 客户端（PowerShell `Invoke-WebRequest`）
核验方式：逐个 URL 实际发起请求，记录**状态码**、**页面标题**、**是否取到正文**。

> [!note] 为什么不用浏览器的网页抓取工具
> 本机域名解析把 `gov.cn` 系域名指向保留网段，网页抓取工具对这类站点一律报「解析到非公网地址」而失败。这是**本机解析环境的问题，不代表链接失效**。因此本次核验全程改用命令行 HTTP 客户端直连，结果等效于浏览器打开。凡下列台账中标「已取到正文」的，均为当场读到条文原文。

## 四、核验结论

1. 全书条目所需的主要法规，**均已取得官方一级来源的全文**，可直接支撑「依据」「来源」两栏。
2. 存在两处版本风险已定性并留档：**《劳动合同法》的现行合订本来源**与**《工伤保险条例》的库内新旧版并存**。
3. 存在一处来源降级：《劳动法》目前只有地方政府转载页。
4. 本次核验**未凭记忆填写任何条号、文号或链接**。所有写入 `sources/` 的文字，均由上述实测页面逐字抄录。
