# 信源核验记录：劳动合同法版本比对

记录人：信源核验员
核验日期：2026-10-03（东八区）
核验对象：《中华人民共和国劳动合同法》2007 年通过原文 与 2012 年修正后重新公布本的一致性

---

## 一、问题是怎么来的

中国人大网上的《劳动合同法》页面（<http://www.npc.gov.cn/c2/c183/c198/201905/t20190522_26978.html>）实测可访问、可读全文，页面标题为「中华人民共和国劳动合同法_中国人大网」。但页内标题下只有一行：

> （2007年6月29日第十届全国人民代表大会常务委员会第二十八次会议通过）

全文用关键词检索，「2012」出现 0 次，「修正」出现 0 次，「2013年7月1日」出现 0 次。

**即：这是 2007 年通过之原文页，不是 2012 年修正后的现行本。** 直接拿它当「现行有效版本」引用，在版本项上就是错的。这正是本仓库 `docs/条目规范.md` 要求「依据栏必须写明版本与施行日期」的原因。

## 二、2012 年改了什么（一手源全文）

来源：全国人大常委会《关于修改〈中华人民共和国劳动合同法〉的决定》，取自中国人大网 <http://www.npc.gov.cn/npc/c2/c12435/c12488/201905/t20190522_76069.html>（HTTP 200，2026-10-03 实测）。页面标注来源为新华网，2012-12-29 发布。

该决定逐字取到后，确认**只修改四条**：

| 修改项 | 条号 | 修改要点 |
| --- | --- | --- |
| 一 | 第五十七条 | 经营劳务派遣业务的准入条件改为四项，注册资本下限由五十万元提高至**二百万元**，并增设行政许可 |
| 二 | 第六十三条 | 同工同酬改为「实行相同的劳动报酬分配办法」，并加重派遣单位与用工单位的义务 |
| 三 | 第六十六条 | 明确劳务派遣为**补充形式**，界定临时性、辅助性、替代性三种岗位的含义，要求控制用工比例 |
| 四 | 第九十二条 | 未经许可经营派遣业务的罚则细化；罚款标准提高为每人五千元以上一万元以下；吊销派遣业务经营许可证 |

施行日期与过渡安排（决定末尾原文）：

> 本决定自2013年7月1日起施行。
> 本决定公布前已依法订立的劳动合同和劳务派遣协议继续履行至期限届满……《中华人民共和国劳动合同法》根据本决定作相应修改，重新公布。

**结论：** 2012 年修正不涉及本书记录的其余任何条文；本决定明确要求「重新公布」，故现行本 = 2007 原文 + 上述四条替换。

## 四、来源安排与残留问题

**当前安排（见 `sources/法规清单.md` L01）：**

- 未受 2012 年修正影响的 21 条：来源引中国人大网 2007 年通过原文页，并注明已与 2012 修正后本比对一致。
- 受修正影响的 4 条：来源引北京市人民政府门户网站转载的现行本，并注明已与全国人大常委会修改决定原文比对一致。

**残留问题（不掩盖）：**

1. 《劳动合同法》2012 修正后的**重新公布本**，核验员未取得中央一级官方静态全文页。中国人大网只提供 2007 年原文；中国政府网政策文件库不收录全国人大制定的法律；国家法律法规数据库的详情页无永久地址、检索接口不可用。
2. 因此受修正影响的 4 条目前依赖地方政府门户转载页。虽然该页与实际修改决定原文逐字一致（已机器比对），但按 `docs/条目规范.md` 的要求，**这类页面只能算临时源**。
3. **待办**：如日后取得国家法律法规数据库或中国人大网的现行合订本永久链接，替换 L01 的来源栏，并删除本记录本条。
