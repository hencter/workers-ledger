# 条目规范

本文件是全书条目的唯一格式权威。改格式必须改这里，并同步 `tools/check-items.mjs` 的校验逻辑。新增或修改条目时先读本文件。

## 与同类项目的差别

通用循证生活指南把证据强度套用医学那套：荟萃分析 > 随机对照 > 队列 > 专家意见。**这套标准用在法律条目上是错的**——法律条文的效力不来自样本量，来自效力位阶；一条法律的约束力高低，看的是它由谁制定、和上位法是否冲突、什么时间生效。

所以本书用三套独立的标注，各管一件事，不互相替代：

| 标注 | 管什么 | 取值 |
| --- | --- | --- |
| **效力位阶** | 这条依据在法院和仲裁委面前的地位 | 法律 / 行政法规 / 部门规章 / 地方性法规 / 司法解释 / 规范性文件 / 地方口径 / 无明文依据 |
| **主张强度** | 你能不能真拿到手 | 可主张 / 可推定 / 倡导性 |
| **举证难度** | 打赢要什么证据，好不好拿 | 易 / 中 / 难 |

再加两组时效字段，因为政策和地方口径会变：`核对日期`、`地域`。

### 效力位阶只有八种取值，缺依据时用「无明文依据」

`效力位阶` 描述的是**依据本身的地位**，它必须是真实的、已核到的法律文件。**它不能填成「待核实」「不确定」这类占位词**——那会让读者以为有一条依据、只是没查清，而实际情况往往是根本没有可援引的条文。

遇到一个问题确实存在、但找不到明文依据的情形，正确写法是：

- `依据：无明文的全国统一规定`（或写明唯一能确认的那部分，例如「《劳动合同法》第四十二条第三项援引了『规定的医疗期』这一概念，但医疗期具体期限出自原劳动部部门规章，本仓库尚未登记」）
- `效力位阶：无明文依据`
- `主张强度：倡导性`（**强制联动**：只要效力位阶是无明文依据，主张强度不得标为可主张或可推定）
- `来源`：写明你尝试过哪些路径、结果如何。找不到来源不等于可以不写来源栏

### 「待核实」是中间态，不是可以发布的状态

`依据`、`来源`、`效力位阶` 里出现「待核实」的条目，表示这条还没追到官方原文。**这类条目属于未定稿**：

- 在校验脚本里会被报为「未定稿」，`--check` 模式下未定稿条目按错误处理
- 未定稿条目**不得随版本发布**。结项前必须二选一：追到原文改成正式条目，或者按上面的方式改写成「无明文依据 + 倡导性」

允许「待核实」存在，是因为它比编一个条号诚实得多。但它是一个待办标记，不是终态。

一句话：**通用指南告诉你法律允许什么，本书记录法律要拿得出手还需要什么。**

## 条目格式

每条固定在三级标题下，字段顺序不可调换，字段名不可改写，缺一项就是不合格。

````markdown
### 8.3 被迫离职也能拿经济补偿，但要证明是被迫

- 适用：用人单位未及时足额支付劳动报酬、未依法缴纳社会保险费，劳动者据此解除合同（《劳动合同法》第三十八条）。
- 成本：时间——从书面通知到仲裁裁决，快则两三个月，一般半年上下；金钱——劳动仲裁不收费，请律师的费用通常自己承担，不在败诉方负担范围内。
- 收益：按工作年限拿经济补偿，每满一年一个月工资，六个月以上不满一年按一年算，不满六个月算半个月（第四十七条）。
- 说人话：公司欠薪或者不给你缴社保，你可以主动辞职，而且照样能拿到按工龄算的补偿，不是只有被裁才有——但辞职时写的理由必须是上面这两条，写了「个人原因」就拿不到了。
- 依据：《劳动合同法》第三十八条、第四十六条第一项、第四十七条（2012-12-28 修正，2013-07-01 施行）
- 效力位阶：法律
- 主张强度：可主张
- 举证难度：中——工资流水、社保缴费记录可自证；「被迫」的因果链要有书面解除通知里写明的理由支撑
- 地域：全国；地方对「未足额支付」的认定口径有差异，广东、江苏对拖欠时长的容忍度不同
- 时效：仲裁申请自知道权利被侵害之日起一年；劳动关系存续期间因拖欠报酬发生的争议不受一年限制，终止后一年内提出
- 来源：<https://flk.npc.gov.cn/>（国家法律法规数据库检索「中华人民共和国劳动合同法」）
- 核对日期：2026-10-03
- 备注：以「个人原因」辞职后主张补偿的，举证责任在劳动者，实践中极难翻转，签字前务必核对离职申请上的理由栏。
<!-- 成本标签: 钱=0 时间=中 毅力=否 收益=大 口径=金钱 -->
````

## 字段说明

**适用**——谁在什么条件下能用上这一条。不写「所有人」「一般来说」这类空话，要落到身份、情形、前提。多条并列适用时逐条列出。

**成本**——分钱和时间两项写，不写「少量」「一些」这类模糊量。能写具体数额区间就写，写不出就写口径（例如「劳动仲裁不收费」）。不含毅力和心理成本，那是「说人话」里要说的事。

**收益**——这一条能换回什么，单位是什么。金额、期限、比例都要写出来；写不出的写清为什么写不出。

**说人话**——把「收益」和「成本」翻成没有法律训练的人一遍能读懂的日常说法，一到三句。不许出现原文依据里没有的事实、数字或结论。不许引一句用户没见过的说法再去评价它。目标读者只看这一行就能做判断。

**依据**——法律文件全称 + 条款号 + 版本与施行日期。「依据」栏只放条文引用，链接一律进「来源」栏。

**来源**——官方全文的链接，优先国家法律法规数据库、中国政府网、最高人民法院官网、人社部官网。禁止知乎、微信公众号、搜狐、网易、百家号等二手转述。链接一个都没有的条目不允许合并。

**备注**——例外、争议、地方差异、常见误解、要提防的坑。不堆链接，至多留一条指向 `docs/` 长文的链接。

**成本标签**——HTML 注释，GitHub 渲染不可见，供 `index.html` 筛选。**位置约定：写在条目的最后一行**（`备注` 之后），这是本仓库正文的统一实践。校验脚本对条目块内任意位置都接受，但新条目请照统一位置写。取值：

```
<!-- 成本标签: 钱=0|少|多 时间=少|中|多 毅力=否|些|是 收益=大|中|小 口径=金钱|时间|自由|健康 -->
```

含义：钱 `0` 不花钱或省钱、`少` 几十到几百元、`多` 上千元或长期显著支出；时间 `少` 一次几分钟、`中` 一次数小时或每周小时级、`多` 每天持续占用；毅力 `否` 做一次就完、`些` 改一个习惯、`是` 长期对抗惯性。口径是这一条主要换回什么。

## 主张强度怎么定

这一栏是本书最需要克制的地方，宁可标低不标高。

| 取值 | 判据 |
| --- | --- |
| `可主张` | 有明确法律条文依据，且有成熟的强制通道（劳动仲裁、诉讼、劳动保障监察、行政执法），实践中权利主张能落地 |
| `可推定` | 有法律条文依据，但存在地方口径差异、裁量空间或条文衔接上的解释争议；主张能不能成立取决于个案 |
| `倡导性` | 只有政策文件、指导意见、部门通知，没有可强制执行的请求权；对方不照做时没有直接救济手段 |

**凡主张强度标 `可推定` 的条目，必须在「备注」里写明不确定在哪，以及去哪查本地口径（12333、参保地社保经办机构、当地劳动人事争议仲裁委员会）。** 说不清不确定在哪的，标 `倡导性`。

**效力位阶标 `无明文依据` 的条目，主张强度只能是 `倡导性`。** 没有可援引的条文，就没有可强制执行的请求权，标成「可主张」是虚高。这类条目的价值在于把问题本身讲清楚、把坑标出来、把人引到该问的地方，不在于许诺一笔钱。

## 举证难度怎么定

| 取值 | 判据 |
| --- | --- |
| `易` | 证据由对方掌握并由法律强制其提供，或存在官方系统记录可自行查询（社保缴费明细、个税申报记录、医保结算记录） |
| `中` | 需要劳动者主动取证并固定（工资流水、考勤记录、聊天记录、邮件、录音），及时留存即可拿到 |
| `难` | 关键事实依赖对方配合或第三方出证，事后基本无法补取；或需证明主观状态（「被迫」「明知」「恶意」） |

**举证难度标 `难` 的条目，必须在备注里写清取证时间和动作**，例如「离职前先导出」，因为事后无法补救。

**写在哪一栏：** 取证时机写在 `举证难度` 栏（在本仓库的正文实践里，这一栏都以「难——……」开头接说明），校验脚本对「`举证难度` 栏」和「`备注` 栏」两处都认可。**位置不限，但内容必须有**——标了难却不写取证时机的条目不合格。

## 核对日期与复核周期

`核对日期` 是最后一次人工打开官方原文核对的日期，格式 `YYYY-MM-DD`。

**超过 180 天未复核的条目，校验脚本报为「待复核」。** 180 天这个数是仓库约定值，不是任何法规的要求；它的依据是社保基数、最低工资标准、地方口径这类内容多数一年一调，半年一查可以在调整发生后及时反映出来，又不至于让复核负担压过写作。

## 时效怎么写

写三层，缺一层就写「无特别时效」并说明：

1. **程序时效**——仲裁申请（一般一年）、民事诉讼（三年）、行政复议与行政诉讼（六十日 / 六个月）、工伤认定申请（一年）等；
2. **起算点**——从哪天开始算，这一项最容易被忽略，「知道权利被侵害之日」和「离职之日」是两个不同的日子；
3. **不适用时效的例外**——例如劳动关系存续期间的拖欠报酬争议不受一年限制。

## 脱敏硬规则

本书公开，入库前逐条过。违反任何一条即不得提交：

1. **不写任何真实姓名、身份证号、手机号、微信号、邮箱、家庭住址、具体工作单位名称**。
2. **不写个人处境**——不出现「本人」「我司」「笔者所在城市」这类指向，也不得出现可反推出具体自然人的经历组合（例如某地某行业某职级的连续事件链）。
3. **不写公司内部数据**——薪资表、人员名单、内部系统截图、项目细节、客户名称一律不入库。
4. **不写个案结论**——不针对具体案件给判断，只写通用口径和该找谁。
5. 原始素材来自个人知识库的，**必须重写为通用表述后再入库**，不整段搬运。重写后按 `docs/核实记录/` 格式留痕。

## 断言的来源要求

法律类条目的「事实」有两种，来源要求不同：

- **规范断言**（法律规定是什么）：必须能指到条文原文，并写明文件全称、条款号、版本、施行日期。转引自地方人社厅转载页的，正式入库前换成一手全文页，换不了的标注「转载页，待换一手源」。
- **实践断言**（实践中怎么判、大概多久、成功率如何）：必须指到裁判文书、官方统计、司法解释或权威裁量指引。**只有个人经验的，不进「收益」栏，只能写进「备注」并明确标注为经验观察。**

### 来源栏与信源表的分工

条目的 `来源` 栏有两种合法写法：

1. **直接给官方全文页链接**——适用于引用集中、链接不多的条目；
2. **条文链接统一登记在 `sources/法规清单.md`，`来源` 栏注明「见 `sources/法规清单.md` 编号 X」**——适用于同一部法规被大量条目引用的情形。这样改一次链接不用改几十个条目。

无论用哪种写法，**校验脚本会交叉核查：条目「依据」里出现的每一部法规全称，都必须能在 `sources/法规清单.md` 里找到**，找不到就报错。所以新增一部法规时，先在信源表里登记，再写引用它的条目。
