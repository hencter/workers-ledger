# 求助与反馈渠道

本文件回答一个问题：**读完这条，我具体该找谁、去哪找。** 正文里反复出现「12333」「当地劳动人事争议仲裁委员会」「社会保险经办机构」「劳动保障监察机构」，这里是它们的入口与定位方法。

> [!warning] 先读这三条，否则会白跑
> 1. **本文件不是法律意见。** 它给渠道，不给个案结论。涉及具体金额、具体争议、正在进行的程序，最终要落到执业律师或对应机关。
> 2. **机构条目只给」查找方法「，不给具体地址。** 劳动人事争议仲裁委员会、劳动保障监察机构、社保经办机构都是**区县一级**设置，全国数以千计，逐个收录必然写出过期地址。给一个错的地址比不给更坏——所以这里教你怎么定位到你自己那一级。
> 3. **热线号码稳定，网站不一定。** 政务网站改版、限流、JS 渲染都会让链接点不开。号码与「政府门户 → 部门」这条路径更可靠。

**核对日期**：2026-10-03。热线的开通情况与网站可用性会变，用之前建议先拨打确认。

## 一、按你的处境直接查

| 你的处境 | 先做这个 | 渠道 |
| --- | --- | --- |
| 正在发生工伤事故、急症、火灾、中毒 | 先打 **120 / 119 / 110**，同时固定现场证据 | 急救与报警优先，权益问题之后再说 |
| 时效快到了（工伤认定 1 年、仲裁 1 年将届满） | **今天就打 12333**，问还剩多少天、该交什么材料 | 12333 人社服务热线 |
| 想知道「我这情况法律上能不能要」 | 打 **12333** 问政策口径；复杂争议问仲裁委立案窗口 | 12333；当地仲裁委 |
| 想知道「单位这么干违不违法、能不能举报」 | 向**劳动保障监察机构**投诉 | 当地人社局劳动保障监察机构；12333 转 |
| 要申请仲裁，不知道去哪、带什么 | 问**劳动合同履行地或用人单位所在地**的仲裁委 | 当地仲裁委立案窗口；12333 转 |
| 社保没缴、少缴、基数不对 | 问**参保地社保经办机构**；补缴向税务/社保征缴部门 | 参保地社保经办机构；12333 |
| 公积金没缴、封存、转移 | 问**工作地住房公积金管理中心** | 当地公积金管理中心；12329 |
| 仲裁已经立案，想查案件进度 | 问受理你案子的那个仲裁委 | 该仲裁委的立案庭 |
| 对仲裁裁决不服、想撤销或起诉 | 看裁决书上写的**法院与期限** | 裁决书载明的法院；立案窗口 |
| 想免费找律师 | 申请**法律援助** | 当地法律援助中心；12348 |
| 心理撑不住、有自伤念头 | 先打心理援助热线 | **12356**（全国心理援助热线） |
| 要核对某条法条的原文 | 查国家法律法规数据库 | https://flk.npc.gov.cn/ |

> 「12333 转」的意思是：12333 是总入口，说明你在哪个区县、要办什么事，接线员会给出对应机构的地址与电话。**这是定位到区县级机构最省事的路径**，比自己在网上搜可靠——网上搜到的「劳动仲裁委员会」很多是过期的或非官方的。

## 二、热线

| 热线 | 用途 | 备注 |
| --- | --- | --- |
| **12333** | 人力资源社会保障服务热线：社保、就业、劳动关系、工伤政策咨询 | 人社部统一号码，各地接听，一般按市话收费 |
| **12348** | 公共法律服务热线：法律咨询、法律援助指引 | 司法部系统；中国法律服务网亦为 12348 |
| **12329** | 住房公积金服务热线 | 缴存、提取、贷款、转移 |
| **12356** | 全国心理援助热线 | 心理危机干预；**不做权益分析，先处理人** |
| **12315** | 市场监管投诉举报 | 涉及用人单位商事登记、虚假招聘广告时可问 |
| **12345** | 政务服务便民热线 | 不知道该找哪个部门时的兜底入口；会把工单转派 |

**怎么用（决定你这一通电话有没有用）**：接通后先讲三件事——**你在哪个区县、单位在哪个区县、事情发生在什么时候**。时效类问题（工伤认定、仲裁时效）第三件事最要紧，先问「还剩多少天」。接下来把要问的问题写下来再打，一次问一件，并**记下接线员的工号或受理编号**。

## 三、机构怎么定位（本文件的核心）

### 1. 劳动人事争议仲裁委员会

- **归口**：由人力资源社会保障部门（人社局）承担其办事机构职责——所以「找仲裁委」通常等于「去你单位或劳动合同履行地的人社局」。
- **管辖**：一般由**劳动合同履行地**或**用人单位所在地**的仲裁委管辖（《劳动争议调解仲裁法》第二十一条）。两地不一致时，由劳动合同履行地管辖更常见；具体问 12333。
- **怎么找**：① 打 12333 说明区县与事由，要受理窗口的地址、电话、办公时间；② 或打开**你所在区县人民政府门户网站**（不是搜「劳动仲裁」，而是进政府站）→「政府信息公开」或「政务服务」→「人力资源和社会保障局」→ 找「劳动人事争议仲裁」栏目。
- **去之前带什么**：身份证、劳动关系证明材料（合同、工资流水、社保记录、考勤或工作沟通记录）、仲裁申请书（按被申请人人数交副本）、证据材料清单。材料细节见 `book/09-维权路径与时效.md`、`book/14-仲裁与诉讼实操.md`。

### 2. 劳动保障监察机构

- **归口**：同样在**当地人社局**下设（劳动保障监察机构/劳动保障监察支队、大队）。
- **管什么**：用人单位违法行为——不签合同、拖欠工资、超时加班、不缴社保等，走**行政查处**路径（责令改正、罚款），与仲裁的「给你个人给付」是两条路。
- **注意时效**：违反劳动保障法律的行为，**2 年内**未被发现、未被举报投诉的，不再查处（《劳动保障监察条例》第二十条）。
- **怎么找**：① 12333 转；② 当地人社局官网 →「劳动保障监察」栏目；③ 也可打 12345 转派。

### 3. 社会保险经办机构与公积金管理中心

- **社保经办**：参保地（通常是工作地所在区县）的社保中心/医保中心。**查自己的缴费明细**一般走线上更快：参保地人社或医保的官方 App/公众号，或全国人社政务服务平台的个人入口。
- **公积金**：工作地住房公积金管理中心；热线 12329。
- **注意**：单位未缴、少缴的**补缴**属行政征缴路径；因未缴造成的**损失赔偿**属仲裁路径。两者时效不同，别混（详见 `book/07-社保公积金与失业之后.md`）。

### 4. 法律援助中心

- **管什么**：为经济困难或特定情形的当事人提供免费律师服务；劳动争议在多数地方属于可以申请的范围，但**受理条件各地不同**。
- **怎么找**：① 打 12348 问当地法律援助中心地址与申请条件；② 区县司法局下设的法律援助中心；③ 部分仲裁委、法院设有法律援助工作站。
- **带什么**：身份证、经济困难证明（各地要求不同）、案件材料。先电话问清再跑。

## 五、打 12333 之前，把这几件事准备好

问得越具体，接线员越能给你有用的答复：

1. **时间点**：事故发生日、离职日、知道权利被侵害日、收到通知日——时效从这些日子算，问「还剩多少天」。
2. **地点**：你在哪个区县、单位注册在哪个区县（决定管辖）。
3. **要什么**：是要「个人拿到钱」（→ 仲裁），还是要「让单位被查处」（→ 劳动保障监察）？两条路要的材料和时效不同。
4. **手上有什么**：合同有没有、工资怎么发的、社保缴到哪个月、有没有书面的解除或催告记录。
5. **写下来**：把问题列成条目，一件一件问；**记下受理编号或工号**，后续再打时可以接上。

## 六、反馈本仓库

发现正文有错、来源失效、或者某个渠道信息过期：

- 提 issue 或 pull request（附上你核对到的官方页面与你实际看到的内容）；
- **不要**在反馈里写真实姓名、单位名称、身份证号、手机号等个人信息——本仓库公开，且 `tools/check-desensitize.mjs` 会对全仓扫描；
- 涉及法规内容的改动，按仓库约定需在 `docs/核实记录/` 留一份改动说明。

本文件的来源登记在 `sources/法规清单.md` 的「二之四、求助与反馈渠道」，链接变动时改那一处。
