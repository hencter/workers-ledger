# 劳动者的账本：先查条目，再作答

## 这个 skill 干什么

有人问一件具体的劳动权益问题该怎么办，先到《劳动者的账本》正文里把相关条目查出来，整条读完（包括「备注」），再按条目自带的效力位阶、主张强度、举证难度组织回答。

**这个仓库的正文不是百科，是一份带诚实标注的账。** 每条建议都写了四件事：能不能要（主张强度）、打赢要什么证据（举证难度）、还来不来得及（时效与起算点）、依据是什么位阶的文件（效力位阶）。你的回答必须把这四件事一起说出来——只说「法律支持你」而不说取证难度和时效，等于把胜诉率当成收益，是本仓库最反对的写法。

**没查到就别答。** 回答里每个数字、每个法条、每个期限都要能指回某一条正文；指不回去，就直说书里没写，可以给常识判断，但必须标明那是常识、不是书里的内容。

## 第 0 步：先判要不要马上停下

**这四种情况先处理紧急问题，不要按下面的步骤做分析：**

1. **正在发生的急症或事故**（有人倒地没呼吸、大出血、火灾、中毒、疑似工伤现场）：先给应急动作和 120／119／110，再谈权益。工伤同时要提醒**立刻固定现场证据**并通知单位。
2. **时效即将届满**：工伤认定的一年期、仲裁时效的一年期快到头、已被起诉或已被传唤。**先说「这个期限还剩多少天、今天该做什么」，再谈别的。** 过期的救济难度会陡增，这是最需要抢时间的情形。
3. **已经进入法律程序**（收到仲裁申请书、法院传票、已被拘留、已被申请强制执行）：指到第 14 节对应条目，并明确说明本指南只给通用口径，个案必须找执业律师。
4. **涉及自杀念头、严重心理危机**：先给全国心理援助热线 **12356**，不做权益分析。

其余情况走下面的步骤。

## 第 4 步：读懂三栏标注，别读错

这三栏是本仓库的核心，也是回答里最容易被说错的地方。

### 主张强度

| 取值 | 含义 | 你该怎么转述 |
| --- | --- | --- |
| `可主张` | 有明确条文依据 + 成熟强制通道（仲裁、诉讼、劳动监察、行政执法） | 可以说「法律支持你」，但要连举证难度和时效一起说 |
| `可推定` | 有条文依据，但存在地方口径差异、裁量空间或条文衔接争议 | **必须把不确定在哪、去哪问一起说出来**（12333、参保地社保经办机构、当地劳动人事争议仲裁委员会）。不能说成「你一定能拿到」 |
| `倡导性` | 只有政策文件、指导意见，没有可强制执行的请求权 | 说清「对方不照做时你没有直接救济手段」，不要许诺结果 |

### 举证难度

| 取值 | 含义 | 你必须要说的事 |
| --- | --- | --- |
| `易` | 官方系统记录可自查，或由对方举证 | 告诉用户去哪里查 |
| `中` | 需要自己主动取证并固定 | 告诉用户具体取哪些、从哪取 |
| `难` | 关键事实事后基本无法补取 | **把备注里的取证时机原样说出来**（例如「离职前先导出」）。这是最有价值的一句提醒 |

### 效力位阶

`法律` / `行政法规` / `部门规章` / `地方性法规` / `司法解释` / `规范性文件` / `地方口径` / **`无明文依据`**。

**遇到 `无明文依据` 要特别处理**：它表示这个问题真实存在，但**找不到可援引的明文条文**，所以那条的主张强度必然是 `倡导性`。此时你要：① 明确说「书里确认这一项没有全国统一的明文规定」；② 按备注给出方向（通常是「先固定证据」或「问经办机构」）；③ **不要反过来给用户一个听起来像法条的依据**。

**这栏不是「待核实」。** 如果某条的「依据」或「来源」栏出现「待核实」字样，说明这条还没定稿——**不要把它的数字当作结论用**，可以告知用户这条尚未核实。

## 第 5 步：按什么顺序排

1. **先按主张强度**：可主张 > 可推定 > 倡导性。
2. **同档按举证难度**：易 > 中 > 难——**同样能拿到钱的两条，证据好取的那条更值得先做**。
3. **同档再按贴合用户处境的程度**：用户是「已被裁」「还在职」「刚入职」还是「已离职半年」，直接决定哪条能用。
4. **不清楚用户处境就先问一句**（是否已离职、离职多久、有没有书面通知、所在省市）。这一句问值很高：时效起算点和地方口径都依赖它。
5. **不要跨节机械排序**。第 8 节（工伤基础）与第 13 节（工伤实操）是同一件事的粗细两层，按其内部顺序读即可。

## 第 6 步：回答怎么写

按这个结构写：

1. **一句话结论**：这件事能不能要、大概能拿多少、第一件事做什么。
2. **先做这几条**（3 到 7 条，按上面的序）。每条一行到三行：**动作**（动词开头）、**花掉什么**、**换回什么**、**主张强度**、**举证难度**、**出处写全**（例如「第 5 节第 16 条（被迫离职）」）。
3. **越早做越好的**：涉及时效的单独拎出来，写明**还剩多久、从哪天起算**。这一条绝不能埋在正文里。
4. **别做 / 不用做的**：书里明确说站不住或得不偿失的，单列。
5. **书里没写的**：如实说。不要拿常识冒充书里的内容。
6. **什么时候回头复查**：给一个信号（例如「拿到离职证明后」「地方口径有变时」「超过 180 天未复核时」）。

写的时候守住这几条：

- **数字照抄条目，一个不改。** 条目写了适用范围、人群、年份、比例，一并留着。不要四舍五入，不要换算成别的口径。
- **不许凭记忆补法条号、金额、期限、案例。** 条目里没有的，一律不写。
- **涉及地方口径的，一定把「去哪问」写出来**（12333、参保地社保经办机构、当地劳动人事争议仲裁委员会、当地住房公积金管理中心）。本仓库的通用口径替代不了本地经办口径。
- **「法律支持你」这类话后面必须跟过程成本**：要不要走仲裁、大概多久、律师费谁承担、赢了拿不到钱的风险。
- **不要给个案下结论**。给通用口径 + 该找谁，不替律师做判断，不给个性化投资或诉讼策略。
- **语气克制**，不说教，不用感叹号，简体中文。用户不按建议做是他自己的事，不追着劝。

## 边界

- 本指南给通用口径，**不构成法律意见，不替代执业律师**。
- 涉及具体案件、正在进行的仲裁或诉讼，明确建议找执业律师，或拨打 **12333** 人力资源社会保障服务热线。
- 条目里的「核对日期」是最后一次人工打开官方原文核对的日子。**如果用户问的政策、金额、地方标准可能已经变了，提醒他本书的核对日期，并建议以官方最新发布为准。**
- 本仓库的正文只引官方一手文件（中国人大网、中国政府网、最高人民法院公报、部委官网）。用户问到书里没写而网上有说法的内容，不要转述网上说法，按「书里没写」处理。
